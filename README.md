# Tiny Mines

A compact minesweeper-style logic puzzle built with Flutter for iOS, Android, and web.
Dig a cozy garden: grass tufts hide sleepy moles, dug soil shows pebble numbers,
and a cleared field bursts into flowers. All art is drawn in code (no image assets).

## Progress

- Best time, wins and plays per difficulty, garden XP and levels, the chosen
  theme, daily results and the daily streak are stored locally under
  `garden_progress_v1`. Older `best_time_<difficulty>` records are migrated on
  load (the faster time wins) and kept in sync.
- Expert garden (feature-expert-garden): a fourth difficulty, 14x14 with 40
  moles and 4 hints (300 XP per win). Its boards are guess-free: a solver that
  only uses visible clues must open every safe tile from your first dig, so a
  hard board never needs a 50:50 guess. Easy keeps its own guess-free
  generator; Normal, Hard, Garden Run and the daily are unchanged.
- Levels unlock cosmetic themes: Spring (Lv1), Autumn (Lv3), Winter (Lv6),
  Night (Lv10).
- Daily garden: one Normal board per local day, the same for everyone, with a
  starting patch already dug. One result per day; finished days build a streak.
- Garden Run: one run over ever bigger boards (5x5 up to 12x12) with 3 hearts.
  A mole costs a heart instead of ending the board, boss gardens (stages 5 and
  10) win a heart back, hints are shared (3, +1 per 3 clears, max 5) and the
  next stage starts by itself. XP is paid once when the run ends (15 per
  cleared board + 10 for taking part); `runsPlayed` and `bestRunStage` are
  saved in `garden_progress_v1`. Normal records and the daily are untouched.
- Garden plots: eight code-drawn plots in two sets. Run Path is earned by
  the Garden Run best stage (2, 3, 5, 7), Daily Beds by scored daily clears
  (1, 2, 4, 7). A complete set pays a one-time XP bonus (100 / 150 XP). The
  collection (N/8 and the next plot) is in My Garden and, on wide screens,
  in the right column. `dailyClears` and `rewardedSets` are stored in
  `garden_progress_v1` (old saves derive `dailyClears` from the daily
  history).
- Board effects (feature-game-feel-polish): dug grass ripples out from the
  tap and each clue pebble pops in after it, a dug mole jumps out of its hole,
  flags spring up, a cleared field blooms. Garden Run shows a short banner for
  every stage start, stage clear, boss garden and the first time a stage earns
  a plot. Flag mode tints the board frame. All effects are one-shot (no
  looping animation) and never block input.
- Every finished run opens a summary (time, best, New best!, XP, level bar,
  unlocks, new plots) with a Next goal block (next level and theme, Garden
  Run target or the closest plot). Enter plays again, Escape shows the board.
- Copy result puts a short ASCII summary on the clipboard. Pages and mobile
  builds append https://bon-on.github.io/TinyMines/, CrazyGames only a
  valid CrazyGames `game.link` from the SDK, GamePix no link. The game never
  opens the link.

## Local Web Build

```sh
flutter build web --release --base-href /TinyMines/
```

GitHub Pages deploys from `.github/workflows/deploy-pages.yml`.

## CrazyGames Web Build

`tool/build_crazygames.sh` builds `build/crazygames/` and the upload zip `build/tiny-mines-crazygames.zip` (no hub link, leaderboard or ads; SDK gameplay events). See `docs/crazygames.md`.

## GamePix Web Build

`tool/build_gamepix.sh` builds `build/gamepix/` and the upload zip `build/tiny-mines-gamepix.zip` (SDK-free; no hub link, leaderboard or ads). See `docs/gamepix.md`. Roboto is bundled in `assets/fonts/` (see `assets/fonts/Roboto_LICENSE.txt`) so web builds make no font requests.

## First run and tutorial

The board is playable right away. First-time players see a short tip strip
above the board (safe first dig, what numbers mean, flags, chord) that can be
hidden with its close button; it also ends after the first finished board.
The full how-to-play card is behind the `?` button (skip with Esc or Skip).
Both use the `tutorial_seen_v1` flag. Until the first Garden Run is played,
a "Try Garden Run" call to action replaces the plain Garden Run entry and
also appears on the result card after a regular win.

## Sound

Sound effects (reveal, flag, boom, win, level up, new best, daily) and a
light, playful music loop share one sound on/off button next to the `?`
button; the choice is remembered via `sound_muted_v1` and CrazyGames muting
(including its settings change events) is respected. On web the music starts
after the first click or key press and pauses while the tab is hidden.
Sounds are generated by `tool/generate_sounds.py` (Python stdlib, deterministic),
no third-party audio. Regenerate them with:

```sh
python3 tool/generate_sounds.py
```
